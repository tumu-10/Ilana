# ILANA Nutrition & Wellness

Nutrition and wellness - a responsive website built with React, TanStack Start, Vite, and Tailwind CSS.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run lint
npm run build
```

## Deployment

The project uses Netlify's TanStack Start Vite plugin for server-side rendering
on Netlify. The `netlify.toml` file configures the production build command and
client asset directory.
